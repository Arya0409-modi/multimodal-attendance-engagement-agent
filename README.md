# Multimodal Attendance & Engagement Agent

An AI-powered capstone project built as part of the Generative AI course.



## Project Overview
The system integrates computer vision, audio signal processing, and agent-based reasoning to automate attendance tracking, analyze engagement dynamics, and provide AI-driven teaching suggestions[cite: 1].

## Scenarios
1. **Automated Attendance Tracking**: Processes live or recorded video feeds to track participants based on sustained presence rather than single-frame detection, eliminating false positives[cite: 1].
2. **Engagement & Session Dynamics Analysis**: Continuously analyzes behavioral indicators such as head pose, movement patterns, inactivity duration, and audio activity to identify attention drops and interaction peaks[cite: 1].
3. **AI-Driven Teaching Suggestions**: Generates context-aware teaching suggestions to assist instructors in adjusting pacing, introducing interactive activities, or addressing classroom management challenges[cite: 1].

## Technical Architecture & Tech Stack
- **Frontend Layer**: HTML5 Templates, CSS3 Styling, JavaScript Controllers, Flask API Gateway[cite: 2].
- **AI Service Layer**: Google Gemini 2.0 Flash, Gemini Image Generation, Text-to-Speech Engine, Code Generation Engine[cite: 2].
- **Storage & Utility Layer**: Generated audio/code files storage and utility management[cite: 2].
